# MVPの画面設計

目的: AIコーディングの「基本料と実際の利用枠」を混同せず読めるリサーチ用一覧。

- 色: 紙面 #ffffff、背景 #f4f7fa、本文ネイビー #192e46、補助 #53677b、確認・リンク青緑 #006d70、境界 #d5dfe7。
- 書体: 日本語はBIZ UDPGothic / Yu Gothic / Meiryo。サービス名はTrebuchet MS。外部フォント不要。金額は等幅数字。
- PC: 左に検索条件、右にサービス別プラン行。情報の系列を揃え、宣伝用の装飾や価格ランキングは設けない。
- モバイル: 検索条件を上部の2列フォームへ移し、本文は1列。制限明細は縦積みで表の横溢れを避ける。

```text
ブランド                            一覧 / 掲載方針
何を調べるサイトか                    誤読を防ぐ注意
検索条件          件数 / 基本料の注意
                  サービス名 + 確認状態
                  概要 / プランごとの料金 / 確認日 / 詳細
```

見直し: 汎用SaaSの大きな件数・料金ヒーローや均一なカードグリッドは避ける。特徴を「本体と契約の区別」と「プラン行」に集約し、それ以外の装飾を抑える。アニメーションなし。見出し、ネイティブフォーム、可視フォーカス、本文へのスキップを用意。
